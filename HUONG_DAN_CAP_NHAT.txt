HƯỚNG DẪN CẬP NHẬT TÀI LIỆU — ERP GUIDANCE PORTAL
======================================================

CÁCH CẬP NHẬT
----------------------------------
1. Mở website ERP Guidance
2. Chọn menu "Quản trị"
3. Đăng nhập admin
4. Chọn khu vực cần cập nhật:
   - Home: PDF / Video tổng quan
   - Module: PDF / Video cho module hoặc sub-module
   - Tài liệu chung: thêm / sửa / xóa tài liệu trong tab "Tài liệu"
5. Dán Google Drive File ID hoặc link đầy đủ
6. Bấm Lưu

Khi bấm Lưu, web sẽ gọi Vercel Function để commit JSON mới lên GitHub.
Sau đó Vercel tự deploy lại từ commit đó.

ĐĂNG NHẬP ADMIN
----------------------------------
Credential được đọc từ env trên Vercel:
  - ADMIN_USERNAME
  - ADMIN_PASSWORD
  - ADMIN_SESSION_SECRET

Nếu chưa cấu hình env, local/dev sẽ dùng mặc định:
  - admin / erp-admin

ENV GITHUB CẦN THIẾT
----------------------------------
  - GITHUB_TOKEN
  - GITHUB_OWNER
  - GITHUB_REPO
  - GITHUB_BRANCH (mặc định: main)
  - GITHUB_CONTENT_PATH (mặc định: site-content.json)

CÁCH LẤY FILE ID TỪ GOOGLE DRIVE
----------------------------------
1. Upload file lên Google Drive
2. Share → "Anyone with the link"
3. Copy link dạng:
   https://drive.google.com/file/d/FILE_ID/view
4. Có thể dán cả link hoặc chỉ dán FILE_ID

TAB TÀI LIỆU
----------------------------------
1. Quy định & Danh mục
   - Hướng dẫn mã code
   - Danh sách ID
   - Danh sách máy
2. Hướng dẫn thao tác
   - Hướng dẫn tạo đơn giao hàng trực tiếp khi có tồn kho
   - Hướng dẫn sử dụng terminal
   - Hướng dẫn tạo lệnh sản xuất
3. Tài liệu tham khảo
   - ERP Demo Flow
   - Giải thích MAC
   - Giải thích loại tồn kho
   - Giải thích các loại lệnh sản xuất

LƯU Ý
----------------------------------
- Không cần server riêng hay database.
- Nội dung được lưu trong GitHub repo.
- Nếu GitHub env chưa cấu hình, chức năng lưu sẽ báo lỗi để tránh lưu nhầm.
- Khi chạy local bằng `npm run dev`, chỉ xem được giao diện; login/save cần Vercel hoặc `vercel dev`.
